## What is under which license

Two licenses are in this tree and the boundary between them is a file
extension.

Every tracked file whose name ends in `.md` is a document of this project and
is under CC-BY-4.0, the Creative Commons Attribution 4.0 International
license. Its text is not carried here. It is published at
<https://creativecommons.org/licenses/by/4.0/legalcode>, so reading it needs a
network where reading [LICENSE](LICENSE) does not, and whether to carry a copy
is a question nobody has answered.

Everything else tracked here is under AGPL-3.0. That includes the manifests,
the workflow files and `data/dipole/flat.json`, which says of itself that it is
a definition rather than a measurement and is this project's own work rather
than a piece of the case archive.

Two files are neither. [LICENSE](LICENSE) is the text of the GNU Affero
General Public License and [DCO](DCO) is the text of the Developer Certificate
of Origin, version 1.1. Both are carried verbatim on the terms their own
authors set, and nothing here relicenses either.

The generated case archive is a third answer and is not in this tree at all.
It is published as a release artefact under CC0-1.0.

Why the documents are freer than the code. They carry arguments and exist to
be read and passed on, and CC-BY rather than CC0 because somebody quoting an
argument should be able to say where it came from. The case archive is
computed rather than written, so attribution buys nothing there. Both answers
were taken by the maintainer on 2026-08-09 and are written in issue #34.

Nothing refuses a document that lands outside this boundary. The boundary is
every tracked `.md` file, which leaves no list for a check to read that a
reader cannot already see, and a document arriving under some other extension
would be covered by the sentence about the code rather than by this one.
